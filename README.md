🏨 Royal Hotel Booking System

Welcome to the Royal Hotel Booking System, a C++ console-based application designed to manage guest bookings, room availability, and stay durations — all with a beautiful terminal layout and user-friendly interaction.

✨ Features

🔹 Add New Guest
Easily register a guest with their personal information, days of stay, and desired room number.

🔹 Room Availability Map
Visualize all rooms (0–99) with intuitive ✅ (available) and ❌ (booked) icons, clearly labeled with room numbers.

🔹 View Guest List
Display a detailed list of all registered guests, including:

Name
Personal number
Room number
Days staying
Total cost
🔹 Search by Personal Number
Quickly find and display guest information by their unique personal number.

🔹 Update Guest Details
Edit any previously entered information, including name, stay duration, room number, or personal number.

🔹 Cross-platform Clear Screen
Automatically clears the terminal screen depending on your OS (Windows/Linux/macOS) for a cleaner experience.
