# Mina C++ Konsolprojekt

Välkommen till min samling av konsolbaserade C++-projekt! Här hittar du flera intressanta program som jag byggt, inklusive bankkontohantering, GitHub-statistik, hotellbokning och bibliotekssystem.

## Projektlista

| Projekt                     | Kort beskrivning                                       | Mapp                  |
|----------------------------|-------------------------------------------------------|-----------------------|
| 🏦 Bank Account Management  | Hantera användare, bankkonton, insättningar och uttag | [BankAccount](./BankAccount) |
| 📊 GitHub Stats Tracker     | Spåra och analysera GitHub-projektstatistik över tid  | [GitHubStatsTracker](./GitHubStatsTracker) |
| 🏨 Royal Hotel Booking      | Hantera hotellbokningar och gäster via terminalen     | [RoyalHotelBooking](./RoyalHotelBooking) |
| 📚 Library System           | Enkel bibliotekshantering med böcker och lån          | [LibrarySystem](./LibrarySystem) |

## Kom igång

1. Klicka in i någon av mapparna ovan för att se detaljerad README och källkod.  
2. Följ instruktionerna för att kompilera och köra varje program.
