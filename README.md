# 💖 Relationship Advice Console App.cpp

A simple, interactive C++ console application offering biblically grounded relationship advice. Navigate through themed wisdom—from finding the right partner to handling conflict—delivered in practical, easy-to-read tips and Bible-based encouragement.

---

## ✨ Features

- **Beautifully themed menu** with emoji for quick navigation
- **Biblical advice** on love, maturity, communication, and more
- **Practical, actionable points** for each topic
- **Pauses after each tip** so you can reflect and read at your own pace
- **Clears the screen** for distraction-free reading (supports Windows and Unix)
- **Graceful exit** with a blessing

---

## 📋 Menu Options

1. **Finding the Right Person**  
   Guidance for choosing a life partner rooted in faith and wisdom.

2. **Emotional Maturity**  
   Signs of emotional health and how to cultivate it in relationships.

3. **Godly Communication**  
   Tips for honest, loving, and faith-filled dialogue.

4. **Red Flags**  
   Warning signs to watch out for in any relationship.

5. **Real Love vs. Infatuation**  
   How to tell lasting love apart from fleeting feelings.

6. **Growing Together Spiritually**  
   Building a Christ-centered relationship through shared growth.

7. **Preparing for Marriage**  
   Conversations and habits to build a strong marriage foundation.

8. **Handling Conflict Biblically**  
   Healthy, scriptural ways to resolve disagreements and grow together.

0. **Exit**  
   Leave the program with a kind farewell.

## 🛠️ How to Build & Run

### Prerequisites

- A C++ compiler supporting C++11 or later (e.g., `g++`, `clang++`, MSVC)
- Terminal/console access

### Compile

```bash
g++ -std=c++11 -o relationship_advice relationship_advice.cpp
```

### Run

```bash
./relationship_advice
```
*(On Windows, run `relationship_advice.exe`)*

---

## 💡 Code Highlights

- **clearScreen()**: Cross-platform screen clearing for a smoother experience.
- **PressEnter()**: Pauses after each tip—press Enter to continue and absorb the advice.
- **Menu-driven loop**: Select a topic and receive a series of helpful thoughts, one at a time.
- **Modular functions**: Each advice section is contained in its own function for easy maintenance and expansion.
