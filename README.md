🖥️ Multi-Utility C++ Console App
A colorful and feature-rich C++ console application that combines:
📊 Math Utilities
🏦 Bank Management System
🔐 Name Encryption Tool
📖 Random Bible Verse Generator
Beautifully formatted menus, emoji icons, and ANSI colors create an engaging user experience.
✨ Features
📊 Math Utilities
➕ Add numbers
🗑️ Delete numbers
📊 Calculate average
📋 Show all numbers
➕ Calculate sum
🏦 Bank Management System
➕ Create new accounts
📋 View all accounts
💰 Deposit money
Auto-generated unique account IDs
🔐 Name Encryption
Encrypt names with a custom character map
Secure and fun text transformation
📖 Random Bible Verse
Displays uplifting Bible verses
Refreshes on every run for daily encouragement
