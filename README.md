## 🧍‍♂️ War Enrollment System Console App

A C++ console application to manage war enrollment registrations with height and age eligibility checks.

**Features:**
- Add new persons with detailed personal info (name, lastname, gender, person number, age, height)
- Show all registered persons with eligibility status based on minimum height requirement
- Update person details (name, lastname, gender, age, height)
- Remove a person by person number with confirmation
- Friendly and clear menu with emojis and layout for better usability

**Minimum height requirement:** 170 cm
